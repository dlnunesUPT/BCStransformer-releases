# BCStransformer – releases

BCStransformer converts IFC, STEP, DWG/DXF and Navisworks models into SCIA Engineer models (SAF). It is made by
Beconsteel Design SRL (BCSteel Design).

This repository holds only the **Windows packages** of each version – see
[Releases](https://github.com/dlnunesUPT/BCStransformer-releases/releases). The app checks this page for new versions
and can install them itself (*Settings › About › Updates*).

## Install

1. Download `BCStransformer-<version>-win64.zip` from the newest release.
2. Unzip it anywhere you can write (for example `Documents\BCStransformer`).
3. Double-click `BCStransformer.exe` (or `run.bat`). Start with *READ ME FIRST.txt* in the folder.

Everything the app needs is inside the folder: nothing is installed in Windows, no administrator rights.

Other files of a release:

- `…-STEP-addon.zip` – OpenCascade for STEP files, for a PC without internet (see *READ ME FIRST.txt*).
- `…-app.zip` – the app without its Python, used by the app's updater.
- `SHA256SUMS.txt` – the checksums of the zips.
